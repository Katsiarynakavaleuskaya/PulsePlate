# Инструкции для текущего PR

## 🎯 Цель

Исправить проблемы с таймаутом CodeRabbit, сохранив обязательность CodeRabbit review для качества кода.

## 🔧 Что изменено

### 1. CodeRabbit теперь ОБЯЗАТЕЛЕН

- **Принцип**: Все PR должны пройти CodeRabbit review
- **Таймаут**: 10 минут (удваивается до 20 минут для PR >100 файлов)
- **Результат**: Workflow падает, если CodeRabbit не завершился

### 2. Умная обработка больших PR

- **Обычные PR**: 10 минут таймаут
- **Большие PR (>100 файлов)**: 20 минут таймаут
- **Логика**: CodeRabbit все еще обязателен, но с большим временем

### 3. Сохранен Quick Merge для экстренных случаев

- **Файл**: `.github/workflows/quick-merge.yml`
- **Использование**: только для критических hotfix

## 📋 Для текущего PR

### Вариант 1: Дождаться CodeRabbit (рекомендуется)

1. Дождитесь завершения CodeRabbit review (до 10-20 минут)
2. Workflow автоматически применит фиксы
3. PR будет готов к merge

### Вариант 2: Quick Merge (только для экстренных случаев)

1. Перейдите в **Actions** → **Quick Merge**
2. Нажмите **Run workflow**
3. Укажите номер текущего PR
4. ⚠️ **Внимание**: CodeRabbit review будет пропущен

## 🚨 Важно

- **CodeRabbit обязателен** для качества кода
- **Workflow падает**, если CodeRabbit не завершился
- **Quick Merge** только для экстренных случаев
- **Автоматические фиксы** применяются после CodeRabbit

## 📁 Измененные файлы

- `.github/workflows/pr-automation.yml` - основной workflow (CodeRabbit обязателен)
- `.github/workflows/quick-merge.yml` - экстренный workflow
- `docs/PR_AUTOMATION_GUIDE.md` - документация
- `CODERABBIT_TIMEOUT_FIX.md` - описание изменений

## ✅ Результат

- ✅ CodeRabbit review обязателен для всех PR
- ✅ Умный таймаут предотвращает блокировку
- ✅ Workflow принуждает к исправлению проблем
- ✅ Качество кода гарантировано
- ✅ Экстренные случаи покрыты Quick Merge
