# Быстрый прогон тестов с байесовским анализом

## Проблема

Кеш-файлы (`__pycache__/`, `*.pyc`, `.pytest_cache/`) попадали в тесты и снижали покрытие, из-за чего тесты проходили долго (10+ минут).

## Решение

1. **Создан `.coveragerc`** - исключает кеш-файлы из измерения покрытия
2. **Обновлены команды** - все команды теперь используют `--cache-clear` для очистки кеша
3. **Создан скрипт `scripts/run_tests_bayesian.py`** - быстрый прогон тестов с байесовским анализом упавших

## Использование

### Быстрый прогон тестов с байесовским анализом

```bash
# Через скрипт
python scripts/run_tests_bayesian.py

# Или через алиас (после source setup_cli_aliases.sh)
pptest-bayesian
```

### Обычные команды (обновлены)

```bash
# Тесты с очисткой кеша
pptest              # Все тесты
pptest-quick        # Быстрые тесты
pptest-failed       # Только упавшие

# Покрытие с исключением кеш-файлов
ppcov               # Покрытие с отчетом
ppcov-check         # Покрытие с проверкой >=97%
ppcov-html          # HTML отчет

# Полная проверка
ppcheck             # Тесты + покрытие + линтинг + форматирование
```

### Через Makefile

```bash
make test           # Тесты (cache cleared)
make test-fast      # Быстрые тесты (cache cleared)
make cov            # Покрытие (cache cleared)
make cov-check      # Проверка покрытия >=97% (cache cleared)
make cov-html       # HTML отчет (cache cleared)
```

## Что изменилось

1. **`.coveragerc`** - исключает кеш-файлы из покрытия:
   - `*/__pycache__/*`
   - `*/tests/*`
   - `*/.pytest_cache/*`
   - И другие нерелевантные файлы

2. **Команды обновлены** - добавлен `--cache-clear`:
   - Все команды очищают кеш перед запуском
   - Покрытие измеряется только для `core` и `app` (не для всего проекта)

3. **Байесовский анализ** - автоматически анализирует упавшие тесты:
   - Определяет критические проблемы
   - Предлагает возможности оптимизации
   - Выдает комплексный диагноз

## Преимущества

- ✅ Быстрее (нет кеш-файлов в покрытии)
- ✅ Точнее (покрытие только для реального кода)
- ✅ Умнее (байесовский анализ проблем)
- ✅ Надежнее (автоматическая очистка кеша)

## Примеры

```bash
# Быстрый прогон с анализом
pptest-bayesian

# Полная проверка перед коммитом
ppcheck

# Только покрытие
ppcov-check
```
