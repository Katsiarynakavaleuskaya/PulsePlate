# 🎬 Руководство по настройке MP4 анимаций

## 📁 **Текущее состояние:**
- MP4 файлы находятся в `ios/PulsePlate/Resources/`
- Создан `SimpleVideoTest` для тестирования
- Кнопка тестирования добавлена в ProfileView

## 🔧 **Что нужно сделать в Xcode:**

### 1. **Добавить MP4 файлы в проект:**

1. **Откройте проект:**
   ```bash
   open ios/PulsePlate.xcodeproj
   ```

2. **Добавьте файлы:**
   - В Project Navigator найдите папку `PulsePlate`
   - Правой кнопкой → "Add Files to 'PulsePlate'"
   - Выберите папку `Resources/` с MP4 файлами
   - Убедитесь, что "Add to target: PulsePlate" отмечен
   - Нажмите "Add"

3. **Проверьте Bundle Resources:**
   - Выберите проект в Project Navigator
   - Выберите Target "PulsePlate"
   - Перейдите на вкладку "Build Phases"
   - Разверните "Copy Bundle Resources"
   - Убедитесь, что MP4 файлы там есть

### 2. **Тестирование:**

1. **Запустите приложение**
2. **Перейдите на вкладку "Profile"**
3. **Нажмите "Test FitChef Animation"**
4. **Проверьте воспроизведение видео**

## 🐛 **Если видео не загружается:**

### **Проверьте консоль на ошибки:**
- `❌ Video not found: [filename]` - файл не найден в Bundle
- `✅ Video loaded: [path]` - файл успешно загружен

### **Возможные решения:**

1. **Файлы не добавлены в Bundle:**
   - Перетащите MP4 файлы в Xcode
   - Убедитесь, что они в "Copy Bundle Resources"

2. **Неправильные имена файлов:**
   - Проверьте, что имена совпадают с кодом
   - Убедитесь, что расширение `.mp4` правильно

3. **Файлы в неправильной папке:**
   - MP4 файлы должны быть в Bundle, не в Assets.xcassets
   - Assets.xcassets только для изображений

## 📱 **Ожидаемый результат:**
- Видео должно воспроизводиться в тестовом экране
- Кнопки "Previous/Next" должны переключать между анимациями
- В консоли должно быть "✅ Video loaded"
