# PlateChart

Кольцевая SVG-диаграмма распределения макронутриентов в тарелке.

## Описание

Компонент отображает соотношение углеводов, белков и жиров в виде цветных сегментов круга.

## Props

- `carbsPct`: процент углеводов (0-100)
- `proteinPct`: процент белков (0-100)
- `fatPct`: процент жиров (0-100)
