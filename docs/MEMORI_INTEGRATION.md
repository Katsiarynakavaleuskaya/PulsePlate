# 🧠 Memori Integration - Преимущества для PulsePlate

## Что дает использование Memori?

Memori - это SQL-native memory engine для AI агентов, который автоматически сохраняет контекст взаимодействий и позволяет приложению "запоминать" пользователей между сессиями.

## 🎯 Ключевые преимущества для PulsePlate

### 1. **Персонализация на основе истории**

**Без Memori:**
- Каждый запрос обрабатывается независимо
- Пользователь каждый раз указывает свои предпочтения
- Нет учета прошлых взаимодействий

**С Memori:**
- Приложение запоминает диетические предпочтения пользователя
- Автоматически учитывает историю запросов
- Предлагает более релевантные рекомендации

**Пример использования:**
```python
from core.memory_config import get_global_memori

# При первом запросе пользователь указывает: "Я вегетарианец"
# Memori сохраняет: user_id="user123" → preference="vegetarian"

# При следующем запросе (даже через неделю)
# Memori автоматически предоставляет контекст: "Этот пользователь вегетарианец"
# Приложение может автоматически фильтровать мясные продукты
```

### 2. **Улучшение качества рекомендаций**

**Сценарий:**
- Пользователь запрашивает план питания
- Через неделю запрашивает рецепты
- Через месяц запрашивает список покупок

**С Memori:**
- Приложение помнит, что пользователь предпочитает низкоуглеводную диету
- Автоматически предлагает рецепты без картофеля и макарон
- В списке покупок исключает неподходящие продукты

### 3. **Сохранение контекста диалогов**

**Без Memori:**
```
Пользователь: "Создай план питания на неделю"
Система: "Какой у вас рост и вес?"
Пользователь: "170 см, 65 кг"
Система: "Какой у вас уровень активности?"
Пользователь: "Умеренный"
... (много вопросов каждый раз)
```

**С Memori:**
```
Пользователь: "Создай план питания на неделю"
Система: "Используя ваши сохраненные данные (170 см, 65 кг, умеренная активность),
          создаю персонализированный план..."
```

### 4. **Аналитика и улучшение сервиса**

Memori сохраняет все взаимодействия в SQL базе, что позволяет:
- Анализировать популярные запросы
- Выявлять паттерны использования
- Улучшать алгоритмы рекомендаций
- Понимать, что пользователи ищут чаще всего

### 5. **Масштабируемость**

**SQL-native подход:**
- Использует стандартные SQL базы (SQLite, PostgreSQL, MySQL)
- Легко интегрируется с существующей инфраструктурой
- Можно использовать ту же PostgreSQL, что и для основного приложения
- Простое резервное копирование и миграция данных

## 🔧 Практические примеры использования в PulsePlate

### Пример 1: Запоминание диетических ограничений

```python
from core.memory_config import get_global_memori

memori = get_global_memori()
if memori:
    # Сохраняем предпочтения пользователя
    memori.add_memory(
        user_id="user123",
        memory="Пользователь вегетарианец, не ест мясо и рыбу",
        metadata={"diet_type": "vegetarian"}
    )

    # При следующем запросе
    memories = memori.search_memories(user_id="user123", query="диетические предпочтения")
    # Автоматически фильтруем продукты
```

### Пример 2: Улучшение рекомендаций планов питания

```python
# Пользователь запрашивает план питания
# Memori помнит, что он предпочитает:
# - Высокобелковую диету
# - Низкоуглеводные продукты
# - Завтрак в 8:00, обед в 13:00, ужин в 19:00

# Приложение автоматически создает план с учетом этих предпочтений
```

### Пример 3: Персонализация списков покупок

```python
# Memori помнит:
# - Пользователь живет в Беларуси (регион BY)
# - Предпочитает местные продукты
# - Бюджет ограничен (LOW_COST флаг)

# Список покупок автоматически включает только доступные в регионе продукты
# с учетом бюджета
```

## 📊 Сравнение: С Memori vs Без Memori

| Функция | Без Memori | С Memori |
|---------|-----------|----------|
| Персонализация | Только на основе текущего запроса | На основе всей истории взаимодействий |
| Контекст | Теряется между сессиями | Сохраняется в базе данных |
| Удобство | Пользователь повторяет информацию | Приложение "помнит" пользователя |
| Качество рекомендаций | Общие рекомендации | Персонализированные на основе истории |
| Аналитика | Нет данных о паттернах | Полная история в SQL базе |

## 🚀 Начало работы

### Минимальная настройка (работает сразу)

```python
from memori import Memori

# Создаем экземпляр (использует SQLite по умолчанию)
memori = Memori()
memori.enable()  # Активирует автоматическое сохранение

# Готово! Memori теперь автоматически сохраняет контекст
```

### Расширенная настройка (через модуль)

```python
from core.memory_config import get_memori_instance

# Использует настройки из переменных окружения
memori = get_memori_instance(
    user_id="user123",
    database_url="postgresql://user:pass@host/db",  # Опционально
    conscious_ingest=True,  # Извлечение сущностей (требует OpenAI API)
)
```

## 💡 Рекомендации для PulsePlate

1. **Начните с базовой настройки** (SQLite) - работает сразу без дополнительной конфигурации
2. **Используйте для VIP пользователей** - персонализация для премиум-подписчиков
3. **Интегрируйте с существующими профилями** - свяжите `user_id` с вашей системой пользователей
4. **Используйте для аналитики** - анализируйте паттерны запросов через SQL запросы

## 🔒 Безопасность

- Все данные хранятся в вашей базе данных (полный контроль)
- Можно использовать шифрование на уровне базы данных
- Соответствует GDPR (данные хранятся локально, не отправляются в облако)
- Можно настроить автоматическое удаление старых данных

## 📈 Метрики успеха

После интеграции Memori вы сможете измерить:
- Увеличение конверсии (пользователи получают более релевантные рекомендации)
- Снижение времени на создание планов (меньше вопросов к пользователю)
- Улучшение удовлетворенности (персонализированный опыт)
- Рост retention (пользователи возвращаются, потому что приложение "помнит" их)
