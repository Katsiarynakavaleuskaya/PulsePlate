## 📚 Дополнительные документы (для деталей)

### Группа 1: Настройка доменов и окружений

#### **[DOMAIN.md](DOMAIN.md)**
**Что внутри:**
- Обзор вариантов доменов (бесплатные/платные)
- Выбор доменов для staging и production
- Ссылки на регистрацию
- Информация про TON платформу

**Когда читать:** Перед регистрацией доменов
**Время:** 10 минут

#### **CLOUDFLARE_SECURITY_SETUP.md**
**Что внутри:**
- Подробная настройка Cloudflare безопасности
- SSL/TLS (Full strict)
- HSTS настройка
- WAF включение
- Rate Limiting для API

**Когда читать:** После регистрации домена в Cloudflare
**Время:** 20 минут + настройка

#### **[../../deploy/CLOUDFLARE_PAGES_WORKERS.md](../../deploy/CLOUDFLARE_PAGES_WORKERS.md)**
**Что внутри:**
- Современный frontend deploy lane через Cloudflare Pages
- Optional Cloudflare Worker proxy для `/api/*`
- Локальный и CI token flow через `CLOUDFLARE_API_TOKEN`
- Команды для ручной сборки и прямого deploy через Wrangler

**Когда читать:** Когда нужен SPA deploy без production domain cutover
**Время:** 10-15 минут

## 🗺️ Маршрут чтения (рекомендуемый порядок)

### Для первого раза (полная настройка):

1. ⭐ **[OVERVIEW.md](OVERVIEW.md)** — главная инструкция
2. **[DOMAIN.md](DOMAIN.md)** — выбор и регистрация доменов
3. **CLOUDFLARE_SECURITY_SETUP.md** — безопасность Cloudflare
4. **[STAGING.md](STAGING.md)** или **[PRODUCTION.md](PRODUCTION.md)** — настройка сервера
5. **GITHUB_SECRETS_SETUP.md** — секреты в GitHub
6. **[../../deploy/CLOUDFLARE_PAGES_WORKERS.md](../../deploy/CLOUDFLARE_PAGES_WORKERS.md)** — modern frontend Pages lane
7. Проверка первого деплоя

### Для быстрого старта:

1. **SOLO_DEPLOYMENT_SETUP.md** — обзор
2. **[OVERVIEW.md](OVERVIEW.md)** — основные шаги
3. Выполнение по инструкции

### Если что-то не работает:

1. **[OVERVIEW.md](OVERVIEW.md)** → раздел "Частые проблемы"
2. Соответствующий тематический файл (например, **[STAGING.md](STAGING.md)** для проблем со staging)

## 🎓 Советы для новичков

1. **Не торопитесь** — читайте каждый шаг внимательно
2. **Выполняйте по порядку** — не пропускайте шаги
3. **Копируйте команды аккуратно** — проверяйте, что копируете правильно
4. **Сохраняйте пароли и ключи** — они понадобятся позже
5. **Делайте скриншоты** — на случай, если что-то забудете
6. **Не бойтесь ошибок** — они нормальны, есть раздел с решениями
