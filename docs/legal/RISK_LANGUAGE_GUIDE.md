# Risk Language Guide (Wellness Products)

**Status:** Canonical (legal compliance)
**Last updated:** 2026-01-15
**Purpose:** Safe communication of health risk information

---

## 🎯 Core Principle

**Communicate risk awareness, not medical diagnosis.**

Language should:
- ✅ Educate
- ✅ Inform
- ✅ Create awareness
- ❌ Not diagnose
- ❌ Not create fear
- ❌ Not replace medical consultation

---

## 📊 Risk Level Communication

### ❌ Bad (Medical/Scary)

```
Высокий риск заболевания
Ожирение опасно для жизни
Критический уровень риска
Требуется срочное лечение
```

### ✅ Good (Wellness/Educational)

```
Факторы, которые могут быть связаны с повышенной нагрузкой на здоровье
Некоторые показатели могут указывать на повышенное внимание к образу жизни
Рекомендуется обратить внимание на образ жизни
Может быть полезно проконсультироваться со специалистом
```

---

## 🧠 Specific Examples

### BMI Category: Overweight

**❌ Bad:**
```
ОПАСНО! Высокий риск сердечно-сосудистых заболеваний!
```

**✅ Good:**
```
BMI в этом диапазоне может указывать на необходимость
обратить внимание на образ жизни и питание.
```

---

### WHR: High

**❌ Bad:**
```
Критический уровень! Немедленно обратитесь к врачу!
```

**✅ Good:**
```
Соотношение талии и бёдер выше обычного может быть связано
с повышенным вниманием к центральному распределению жира.
```

---

### Risk Staging: Moderate

**❌ Bad:**
```
Умеренный риск заболеваний. Требуется лечение.
```

**✅ Good:**
```
Несколько факторов указывают на то, что может быть полезно
обратить внимание на образ жизни и проконсультироваться со специалистом.
```

## 📋 Risk Level Naming

### Safe Terminology

| Risk Level | Safe Name | Context |
|------------|-----------|---------|
| Low | "низкий" / "low" | Safe, but explain it's not medical |
| Moderate | "умеренный" / "moderate" | Educational, not alarming |
| High | "повышенный" / "elevated" | Avoid "high risk" (medical) |

**Never use:**
- "критический" / "critical"
- "опасный" / "dangerous"
- "смертельный" / "fatal"

## 🧬 Scientific Accuracy

### ✅ Accurate Statements

```
BMI не учитывает распределение жира.
WHR учитывает половые различия.
FFMI отражает мышечную массу.
```

### ❌ Inaccurate / Overreaching

```
BMI точно показывает ваш вес.
WHR диагностирует ожирение.
FFMI лечит недостаток мышц.
```

## 🌍 Regional Variations

### CIS (RU / BY / KZ)

**Safe:**
- "требует внимания"
- "рекомендуется проконсультироваться"
- "может быть полезно"

**Avoid:**
- "опасно"
- "критично"
- "необходимо лечение"

### EU

**Safe:**
- "may indicate"
- "suggests attention"
- "consider consulting"

**Avoid:**
- "dangerous"
- "critical"
- "requires treatment"

### US

**Safe:**
- "may be associated with"
- "suggests lifestyle attention"
- "consider professional consultation"

**Avoid:**
- "dangerous"
- "life-threatening"
- "requires medical intervention"

## 🔄 Template Phrases

### Opening Risk Communication

**RU:**
```
Некоторые показатели могут указывать на...
```

**EN:**
```
Some indicators may suggest...
```

### Closing Risk Communication

**RU:**
```
Рекомендуется обратить внимание на образ жизни
и при необходимости проконсультироваться со специалистом.
```

**EN:**
```
It may be helpful to pay attention to lifestyle factors
and consider consulting with a healthcare professional if needed.
```
