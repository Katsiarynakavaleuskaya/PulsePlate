# Copywriting Rules for Wellness Products (Canonical)

**Status:** Canonical (legal compliance)
**Last updated:** 2026-01-15
**Purpose:** Prevent regulatory triggers, maintain wellness positioning

---

## 🚫 Prohibited Language (Hard Rules)

### Medical Claims

| ❌ Forbidden | Why | Alternative |
|--------------|-----|------------|
| "диагностирует" | Medical claim | "показывает ориентир" |
| "лечит" | Medical treatment | "может помочь понять" |
| "снижает риск заболеваний" | FDA / MDR trigger | "способствует осознанности" |
| "рекомендуется врачами" | Unprovable claim | "основано на научных данных" |
| "медицинский калькулятор" | Medical device | "wellness-калькулятор" |
| "предотвращает болезни" | Medical claim | "помогает следить за здоровьем" |

### Fear-Based Language

| ❌ Forbidden | Why | Alternative |
|--------------|-----|------------|
| "опасно" | Creates fear | "требует внимания" |
| "высокий риск смерти" | Medical claim | "факторы, требующие внимания" |
| "необходимо срочно" | Medical urgency | "рекомендуется проконсультироваться" |

## ✅ Safe Language (Always Use)

### Educational Framing

| ✅ Safe | Context |
|---------|---------|
| "образовательная оценка" | FREE tier |
| "ориентир" | BMI result |
| "осознанность риска" | PRO tier |
| "может помочь понять" | General |
| "для общего понимания" | Explanations |

### Wellness Positioning

| ✅ Safe | Context |
|---------|---------|
| "wellness-приложение" | Product description |
| "образ жизни" | Lifestyle focus |
| "самостоятельная оценка" | Self-check |
| "информационный характер" | Disclaimers |

## 🧠 Risk Language Guidelines

### ❌ Bad (Medical/Scary)

```
Высокий риск заболевания
Ожирение опасно
Критический уровень
```

### ✅ Good (Wellness/Educational)

```
Факторы, которые могут быть связаны с повышенной нагрузкой на здоровье
Некоторые показатели могут указывать на повышенное внимание к образу жизни
Рекомендуется обратить внимание на образ жизни
```

## 📋 Tier-Specific Language

### FREE Tier

**Safe:**
- "базовая оценка"
- "первый ориентир"
- "образовательная информация"

**Avoid:**
- "точный результат"
- "полная оценка"
- "медицинский скрининг"

### PRO Tier

**Safe:**
- "расширенная интерпретация"
- "индивидуальный контекст"
- "детальная оценка"

**Avoid:**
- "медицинская диагностика"
- "профессиональная оценка"
- "врачебное заключение"

### VIP Tier

**Safe:**
- "персональный план"
- "автоматизация здорового образа жизни"
- "практические рекомендации"

**Avoid:**
- "лечебное питание"
- "диетическое лечение"
- "медицинская программа"

## 🌍 Regional Considerations

### CIS Markets (RU / BY / KZ)

**Safe:**
- "справочный характер"
- "образовательные цели"
- "для общего понимания"

**Avoid:**
- "медицинская деятельность"
- "диагностика"
- "лечение"

### EU Markets

**Safe:**
- "wellness purposes"
- "educational information"
- "lifestyle guidance"

**Avoid:**
- "medical device"
- "diagnostic tool"
- "therapeutic"

### US Markets

**Safe:**
- "wellness application"
- "educational tool"
- "lifestyle support"

**Avoid:**
- "FDA-approved"
- "medical device"
- "therapeutic"

## 🔍 Review Checklist

Before publishing any copy, verify:

- [ ] No medical claims
- [ ] No fear-based language
- [ ] Educational framing
- [ ] Wellness positioning
- [ ] Disclaimers present
- [ ] Regional compliance

## 📚 Examples

### ✅ Good Copy (FREE Result)

```
Ваш BMI: 26.4
Категория: Избыточный вес

Этот показатель может указывать на необходимость
обратить внимание на образ жизни.

⚠️ BMI не учитывает распределение жира и половые различия.
```

### ❌ Bad Copy (FREE Result)

```
Ваш BMI: 26.4
⚠️ ОПАСНО! Высокий риск ожирения!

Немедленно обратитесь к врачу.
```
