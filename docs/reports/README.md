# Reports (Status / Fix Logs / Summaries)

Short-lived or historical documents: progress logs, fix summaries, coverage reports.

## Contents
- [`CURRENT_STATUS.md`](CURRENT_STATUS.md) — current work status snapshot
- [`PROGRESS_LOG.md`](PROGRESS_LOG.md) — progress summary log
- [`FIX_LOG.md`](FIX_LOG.md) — consolidated fixes summary / history
- [`COVERAGE_REPORT.md`](COVERAGE_REPORT.md) — coverage improvements and notes
- [`COMMIT_3_PLAN.md`](COMMIT_3_PLAN.md) — detailed plan for a past/targeted commit (historical reference)

## Notes
When a report becomes outdated, prefer moving it to [`../archive/<YYYY-MM-DD>/`](../archive/) with a dated folder.
