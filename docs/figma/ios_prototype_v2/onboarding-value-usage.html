Потом планы.

Мы не просим длинную анкету в первый экран. Начните с базовых метрик, а потом открывайте PRO и VIP-инструменты тогда, когда они реально нужны.

Порядок использования

✓
BMI Calculator Быстрый вход, мягкий paywall hook и понятная отправная точка.
✓
Plate + Profile Дневной сплит и персональные цели без лишней сложности.
✓
Недельный план и список покупок PRO-вход на домашнем экране, VIP-апгрейд там, где он действительно объясним.

Что важно в v2

Новый прототип собирается как набор чистых экранов без длинных scroll-capture дублей, поэтому дальше его можно безопасно использовать как implementation reference.
