# Checklist de carga App Store Connect

- Localizacion: solo `es-ES` para este paquete.
- Dispositivo base: `iPhone 6.9-inch` (`1320x2868` o tamano compatible permitido).
- El orden de capturas coincide exactamente con `shot_manifest.json` del frame `01` al `07`.
- Titulos y textos de apoyo permanecen dentro del area segura gobernada.
- La posicion de FitChef no cubre UI clave y usa solo asset keys canonicos.
- Los metadatos coinciden con `app_store_metadata.json`.
- El texto se mantiene en apoyo de planificacion diaria, sin rol profesional,
  promesas de resultado o estados de producto fuera del canon.
- Ninguna captura o escena preview muestra UI inventado, texto placeholder o
  funciones no canonicas.
- El icono de marketing de App Store se puede rastrear al inventario aprobado.
- Activos `EN` / `RU` no se mezclan con este set `es-ES`.
- Carga Fastlane, cambios en App Store Connect, export de capturas y export de
  preview-video quedan fuera del alcance de este paquete.
