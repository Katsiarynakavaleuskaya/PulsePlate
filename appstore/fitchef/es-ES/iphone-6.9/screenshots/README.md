# Paquete de capturas FitChef ES

Esta carpeta guarda el manifiesto gobernado de capturas en español para la
ola de localización FitChef en App Store.

El paquete solo prepara el futuro paso de capture/export. No contiene archivos
binarios finales de capturas.

El orden esperado de export y los nombres de archivo están fijados en
`shot_manifest.json`.

El manifiesto repite la secuencia gobernada EN/RU de siete frames, pero
localiza títulos y texto de apoyo para `es-ES`. Las superficies del producto,
referencias de fuente, áreas seguras y asset keys de mascota siguen vinculadas
al canon actual del repositorio.

Fastlane, App Store Connect, export de capturas y evidencia protegida de
release quedan fuera del alcance de este archivo.
