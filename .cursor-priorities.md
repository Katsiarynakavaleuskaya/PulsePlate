# Cursor AI Model Priorities for PulsePlate

## 🎯 **Primary Models (OpenAI Pro Account)**

### **GPT-5** - Основная модель
- **Использование**: Сложные архитектурные решения, анализ кода, планирование
- **Сильные стороны**: Продвинутые рассуждения, понимание контекста, стратегическое мышление
- **Примеры задач**:
  - Анализ архитектуры FastAPI + iOS
  - Планирование новых фич
  - Оптимизация производительности
  - Code review и рефакторинг
  - Сложные алгоритмы и паттерны

### **Codex** - Вторичная модель
- **Использование**: Генерация кода, рефакторинг, автодополнение
- **Сильные стороны**: Специализация на коде, понимание синтаксиса, генерация функций
- **Примеры задач**:
  - Генерация SwiftUI компонентов
  - Создание FastAPI endpoints
  - Написание тестов
  - Рефакторинг legacy кода
  - Автодополнение и исправление ошибок

## 🔄 **Fallback Model**

### **Grok-3** - Резервная модель
- **Использование**: Альтернативные решения, креативные подходы
- **Сильные стороны**: Нестандартное мышление, новые идеи
- **Примеры задач**:
  - Генерация идей для UX
  - Альтернативные архитектурные решения
  - Креативные подходы к проблемам

## ⚙️ **Настройка в Cursor**

1. **Settings → AI → Models**
2. **Primary**: GPT-5 (OpenAI Pro)
3. **Secondary**: Codex (OpenAI Pro)
4. **Fallback**: Grok-3 (CometAPI)

## 🚀 **Преимущества такой конфигурации**

- **GPT-5**: Продвинутое понимание контекста проекта
- **Codex**: Специализация на генерации кода
- **Grok-3**: Альтернативные перспективы
- **Pro возможности**: Доступ к самым мощным моделям OpenAI
- **Гибкость**: Переключение между моделями по необходимости
