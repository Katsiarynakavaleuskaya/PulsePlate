# CodeRabbit Timeout Fix

## Проблема

CodeRabbit занимает слишком много времени для больших PR, блокируя автоматический merge.

## Решение

### 1. Обновлен таймаут CodeRabbit

- **Было**: 15 минут
- **Стало**: 20 минут для больших PR (10 минут базово с автоматическим удвоением)
### 2. CodeRabbit теперь ОБЯЗАТЕЛЕН

- **Принцип**: CodeRabbit review требуется для всех PR
- **Исключение**: только для очень больших PR (>100 файлов) с удвоенным таймаутом
- **Результат**: workflow падает, если CodeRabbit не завершился в срок

### 3. Умная обработка больших PR

- **Условие**: более 100 измененных файлов
- **Действие**: таймаут удваивается (20 минут)
- **Логика**: CodeRabbit все еще обязателен, но с большим временем

### 4. Новый Quick Merge workflow

- **Файл**: `.github/workflows/quick-merge.yml`
- **Назначение**: быстрый merge без CodeRabbit
- **Запуск**: Actions → Quick Merge → Run workflow

## Как использовать

### Для текущего PR

1. Дождитесь завершения CodeRabbit review (до 10-20 минут)
2. Или используйте Quick Merge workflow для экстренных случаев

### Для будущих PR

- **Малые PR**: используйте стандартный workflow (CodeRabbit обязателен)
- **Большие PR**: CodeRabbit обязателен с удвоенным таймаутом
- **Срочные изменения**: используйте Quick Merge (только для экстренных случаев)

## Файлы изменены

- `.github/workflows/pr-automation.yml` - основной workflow
- `.github/workflows/quick-merge.yml` - новый быстрый workflow
- `docs/PR_AUTOMATION_GUIDE.md` - подробная документация

## Результат

- ✅ CodeRabbit теперь обязателен для всех PR (качество кода)
- ✅ Умный таймаут: 10 минут для обычных PR, 20 минут для больших
- ✅ Workflow падает, если CodeRabbit не завершился (принуждает к исправлению)
- ✅ Quick Merge доступен для экстренных случаев
- ✅ Автоматические фиксы применяются после CodeRabbit review
- ✅ Тесты запускаются и проверяются
